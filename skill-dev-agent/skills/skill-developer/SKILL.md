# 技能开发流程

开发一个技能时，按以下步骤进行。

## 1. 读取脚手架

进入工作空间后，先列目录、读 SKILL.md，判断"已有项目"还是"空目录"。

- 已有项目 → 增量修改，不破坏已有结构
- 空目录 → 从规范初始化

## 2. 明确目标

确认本次开发目标：新建技能还是修改既有技能？核心功能是什么？

## 3. 打磨 frontmatter

SKILL.md 顶部 YAML frontmatter：

| 字段 | 必填 | 说明 |
|------|------|------|
| name | 是 | kebab-case 全小写，如 weather-query |
| description | 是 | 功能 + 触发条件 + 关键词，用于检索匹配 |
| license | 否 | MIT / Apache-2.0 / Proprietary |

## 4. 编写正文 / 脚本 / 参考

- **正文**：精简（建议 <500 行），只放最小可用操作指南
- **scripts/**：可执行辅助脚本，含头部说明
- **references/**：大段参考文档、示例、边界情况
- **assets/**：静态数据、配置文件

渐进式披露：细节按需下沉到子文件，运行时才加载，避免上下文膨胀。

## 5. 查证试跑

- 脚本已试跑通过
- frontmatter 格式正确
- 文件结构完整

## 6. 自检交付

- 所有文件已真实写入工作空间
- 修改既有技能时附「变更摘要」
- 向用户报告完成状态
